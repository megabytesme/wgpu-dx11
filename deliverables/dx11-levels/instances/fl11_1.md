## Ordered implementation and test gates

1. Request FL11_1 explicitly and assert the returned enum and `GetFeatureLevel` plus usable `ID3D11Device1` and `ID3D11DeviceContext1`. Retain `E_INVALIDARG` from a runtime without the enum before issuing any separately logged lower-tier request. Check twelve required `D3D11_OPTIONS` members one by one, retaining optional SAD4/extended doubles and later-runtime capability results independently.
2. Read back CS and OM usage at valid low slots, u8 and u63, and reject u64 and RTV overlap. Use VS, HS, DS, GS and PS to contribute to separate atomic bits or byte ranges with no dependency on cross-stage issue order. Assert the FL11_0 control rejects vertex UAV visibility and CS u8. Test contention, hazard unbinding, and slot reuse across render/compute and replay.
3. Execute per-format integer logic ops with known bitwise destinations and correct masks. Exercise conflicting blend+logic, wrong format and general feature opts. Run target-independent rasterizer forced sample 1 with MRT, 4/8/16 under defined target/DSV rules, and forced 16 with UAV only. Record forced count 3 and invalid DSV/sample-frequency behavior via defined validation or debug diagnostics.
4. Bind a >64 KiB constant buffer through a valid aligned 4,096-constant window. Update a subrange, verify neighboring data, getter windows, and reject impossible offsets/alignment through defined validation. Exercise required NO_OVERWRITE, partial copies, matching overlap semantics, ClearView sentinel rectangles, discard followed by complete initialization, shared synchronization and extended Texture2D sharing. Confirm packed 16-bpp uses at the runtime-qualified boundary and verify each operation behind its option.
5. Run all FL11_0 shaders and indirect, MSAA, tessellation, SO, sync, and query cases on the elevated device. Verify product shader compatibility, GPU-side features and runtime display path with paired settings. Record availability before benchmarking. Perform the device-loss/recreation and AppContainer resume checks and repeat all lower-tier gates.
