## Ordered implementation and test gates

1. Reproduce FL9_1 and add strict FL9_2 selection under a named fixture. Shader compile/create/execute the same `vs_4_0_level_9_1` and `ps_4_0_level_9_1` workload, with `ps_4_0_level_9_3` as a negative control. Materialize queried optional results independently of actual selected level.
2. Exercise U16 and U32 index buffers with raw indices 65,534, 65,535, and 65,536 as applicable, raw 1,048,575 at the documented FL9_2 boundary, and a separate invalid 1,048,576 companion. Distinguish list/strip restart and stored index from signed base vertex. Draw exactly 1,048,575 point/triangle-list primitives with a terminal sentinel and validate the over-boundary behavior: a rejected native operation and, if implemented, legal split public draws. Track combined resource usages separately before changing `UNRESTRICTED_INDEX_BUFFER`.
3. Render opposite windings with different D24S8 front/back stencil operations and compare stencil-dependent colors. Change RGB and alpha blend equations with alpha codes distinguishing the two paths, and verify native sRGB-domain blending through an offscreen oracle. Prove overlapping vertex attributes with different offsets/formats and public acceptance/validation. Reject front/back and blend features on lower-tier paths where the inherited contract disallows them.
4. Run empty and visible occlusion queries, two slots with different sample counts and reuse after queue completion. Verify 64-bit results at aligned resolve offsets and reject missing query, duplicate begin/end, invalid resolve offset and out-of-range index. Use native event and predicate coverage separately. Preserve timestamp/disjoint qualification independently.
5. Prove extent 512 on each volume axis and a beyond-guarantee boundary using thin POT resources, the terminal-slice sentinel and legal transfers. Exercise repeat 2,048 at the pixel level, anisotropy transitions 2→3→16 with angled patterns and invalid 17, and native `MIRROR_ONCE` vs repeating mirror. Check signed RG16 data, normalized-16 and float feature/usage rows individually. Test required display/copy/depth rows in the matrix and keep optional NPOT, depth comparison, filtering, or timestamps conditional.
