## Ordered implementation and test gates

1. Exercise 16,384 texture/cube axes, 2,048 volume axes and array layers, and up to 341 complete cubes within memory limits. Prove positive terminal readback and invalid +1 boundaries. Extend typeless and format views as required, plus BC6H UF16/SF16 and BC7 UNORM/sRGB mips/cubes and applicable 3D cases. Validate row pitch, block edges, alignment and sRGB. Test D32F/S8 and test all mandatory 4×/8× format usages per matrix.
2. Compile, create and execute SM5 VS/PS plus `cs_5_0`, and native `gs_5_0`, `hs_5_0`, `ds_5_0`. Run native tessellation tri/quad/isoline with known output, 1/32 control points, invalid 33, fractional odd/even and factor boundary/culling. Test GS adjacency, 32 instanced GS bounds, four independent streams, overflow and DrawAuto. Preserve FL10_1 as the negative runtime for SM5-only profiles.
3. Test 1,024 workgroup invocations, Z=64 and 32 KiB shared-memory reductions, dispatch 65,535 independently on each dimension, and the immediate over-limit cases. Exercise u7 and reject u8 in CS. Test raw/structured SRV and UAV, atomics, required R32 typed loads/stores and per-format optional loads separately. Verify pixel UAVs at writable OM slots with RTV occupancy, negative overlapping bindings or vertex UAV, and resource transitions UAV→vertex/SRV/indirect/copy and back. Test counter append/consume and CopyStructureCount with native expectations.
4. Execute GPU-written indirect args via the 16/20/12-byte draw/indexed/dispatch commands, signed base vertex and first instance. Check zero-count work and alignment/usage/range rejects. Validate resource clear, reuse across passes/lists, query disjoint scopes and completion. Execute maximum legal arrangements, including an eight-RTV pass and a pass with a one-RTV/seven-UAV compact assignment. Do not infer independently maximized resource budgets.
5. Verify Horizon shader API 0.2 forward path, optional HDR format/presentation, and compute culling plus direct/indirect hygiene at matched settings. Run CPU and valid GPU timing, and log any blocked AppContainer hardware path separately.

## Native/public blockers

Hull/domain tessellation, native GS/adjacency and stream output, DrawAuto, native explicit slot/control state, hidden UAV counters, multi-viewport and exact native MSAA quality selection are public API blockers. Record native probe coverage separately. The shared RTV/UAV slot budget needs a public-compatible rule before advertising graphics writable storage.
