# FL9_1 certification blockers

**INCOMPLETE.** The current candidate adds bounded repeat and selected-device sRGB verification. The requirements below still block certification.

| Requirement | Observed gap | Evidence needed to close |
| --- | --- | --- |
| BGRX8 linear and sRGB | Guarded DX11 interop now exposes typed native textures and checks initialization for copies, staged reads and mip generation. The volume path uses native sampling for readback and follows the 10Level9 direct-copy restriction. | Repeat the typed operation matrix on ARM. Determine the blend transfer rule on ceiling hardware. The RTX default-adapter FL9_1 control matched the linear-space model despite the documented encoded-space rule. |
| Native mip generation | The guarded native path issued `GenerateMips` and read back all seven typed 2D formats, including cube faces. It validates ownership, creation flags, initialized source mips and the suffix-view rule. | Run the same implementation on ARM and on a true FL9_1-ceiling driver. |
| FL9_1 blend and sampler semantics | Core accepts direct 2D constant-coordinate Repeat and MirrorRepeat within the proven range. The selected-device probe gates single-sample portable RGBA8 and BGRA8 sRGB blending per format. | Verify arbitrary coordinates, explicit LOD and bias over patterned mip views, and restricted NPOT on physical hardware. Expand the blend fixture across legal equations, factors, masks and RTV paths. Rerun the native blend and repeat controls on ceiling hardware. |
| 10Level9 clipping and shader budgets | The guarded native context exercised all six clip planes. The public shader path rendered eight user varyings with a declared unused `SV_Position` and rejected a ninth. Public `CLIP_DISTANCES` remains unavailable. | Prove the remaining instruction, sampler, temporary-register and dependency boundaries in draws. Rerun the native clipping and eight-varying fixtures on ARM. |
| Other native operations | The matrix records direct texture map, shared-resource paths, driver-level fixed function and output controls, and cube-face render/cube-depth limitations. Some source tables describe driver obligations while the 10Level9 API restricts the application operation. | Add scoped native controls and, where the literal goal requires reachable wgpu behavior, define an extension or emulation. Resolve all `SOURCE_DIFFERENCE` rows against the runtime and intended API surface. |
| Historical hardware and true removal | Exact FL9_1 on RTX 3090 Ti and Adreno 680 validates those execution paths. Their D3D11 ceilings are FL11_1. Fixture-based surface failures and the nominal removed-reason check leave physical removal and recovery unverified. | Supply a physical adapter whose maximum D3D11 feature level is 9_1, with its original driver. Arrange an isolated and recoverable physical removal test. |
| ARM32 Lumia presentation and low memory | The signed native control queued two visible CoreWindow presents at exact FL9_1. The signed wgpu probe installed and logged exact hardware selection, then stopped writing its receipt before the first recorded frame. A signed dispatcher-host update is ready, and the last Portal attempt timed out before upload. | Run the dispatcher-host update via the paired Portal. Collect wgpu frame and resize receipts, rotation, suspend/resume, recovery and the 4 MiB gameplay fallback on a copied world. |
| Surface signed UWP presentation | The ARM64 pre-NPOT-fix repeat and blend fixtures passed offscreen. Interactive HWND automation did not publish a result. The signed ARM64 panel probe built and verified, and SSH timed out before upload. | Restore the Surface SSH path and exercise the final portable tests on the interactive console, the signed real SwapChainPanel fixture and the required product fixtures. |
| Remaining public and conformance coverage | The audit has 684 unresolved exclusions, 439 format- or usage-conditional selectors and two selectors conditional on the sRGB blend probe. Eighteen copy validation cases failed during texture setup. Three historical mixed image-copy parents still need a persistent capability-aware test split. | Separate eligible copy validation from native format and mip restrictions. Resolve the remaining MSAA, browser canvas and WGSL checks and supply native, public, product and performance receipts for the remaining contract cells. |

The DX11 extension starts at `Device::as_hal` and uses the same immediate-context lock as HAL queue submission. Its native textures have their own initialization and ownership tracking. The native context callback supports authored D3D11 commands on independently owned resources.
